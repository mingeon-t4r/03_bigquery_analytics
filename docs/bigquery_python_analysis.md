# Day 11 — BigQuery와 Python 연동 분석

## 1. 분석 목적

BigQuery에서 SQL로 조회한 데이터를 Python의 pandas DataFrame으로 변환하고, SQL과 Python의 집계 결과를 비교하여 일관성을 검증한다.
또한 Station 519의 월별 출발 이용량을 시각화하고, 관측되지 않은 기간을 식별하여 누락 데이터가 분석 결과에 미치는 영향을 확인한다.

## 2. 분석 환경

- Google Cloud 프로젝트: `bigquery-analytics-study`
- BigQuery 데이터셋: `bigquery_learning`
- 분석 테이블: `station_monthly_summary`
- 분석 대상: Station 519
- 사용 기술: BigQuery SQL, Python, pandas, matplotlib
- 인증 방식: Google Cloud Application Default Credentials

## 3. BigQuery와 Python 연동

Python의 `google.cloud.bigquery.Client`를 사용하여 BigQuery에 연결했다.
`client.query()`로 SQL을 실행하고, `query_job.result()`를 통해 조회 결과를 수신했다.
조회 결과는 `to_dataframe()`을 사용하여 pandas DataFrame으로 변환했다.

2017년 4월 Station 519의 출발 이용량은 12,408건으로 확인됐다.

## 4. SQL과 pandas 집계 검증

| 검증 항목 | SQL 결과 | pandas 결과 | 일치 여부 |
|---|---:|---:|---|
| 관측 월 수 | 53 | 53 | 일치 |
| 총 출발 이용량 | 551,078 | 551,078 | 일치 |
| 월평균 출발 이용량 | 10,397.70 | 10,397.70 | 일치 |

세 항목의 비교 결과가 모두 `True`로 나타났다.
이를 통해 동일한 데이터에 대한 SQL 집계와 pandas 집계가 일치함을 확인했다.

## 5. 월별 이용량 시각화

Station 519의 월별 출발 이용량을 matplotlib 선 그래프로 시각화했다.
그래프에서는 겨울철 이용량이 상대적으로 낮고 봄부터 가을까지 증가하는 반복적인 양상이 관찰됐다.
또한 2016년 10월부터 2017년 3월까지 그래프의 선이 끊어진 구간을 확인했다.

관측값이 없는 월을 임의로 0으로 채우지 않기 위해 `asfreq("MS")`를 사용하여 연속적인 월별 인덱스를 생성하고 누락값을 `NaN`으로 유지했다.

## 6. 누락 데이터 검증

| 항목 | 결과 |
|---|---:|
| 전체 월 수 | 59 |
| 관측 월 수 | 53 |
| 누락 월 수 | 6 |
| 원본 이용량 합계 | 551,078 |
| 변환 후 이용량 합계 | 551,078 |

누락 기간은 다음과 같다.

- 2016-10
- 2016-11
- 2016-12
- 2017-01
- 2017-02
- 2017-03

월별 인덱스 변환 전후 총 이용량이 동일했으며, 누락값도 유지됐다.

## 7. 분석 결과 및 해석

Station 519의 관측된 53개월간 총 출발 이용량은 551,078건이며, 관측 월 기준 평균은 10,397.70건이다.
월별 이용량은 계절에 따라 변동하는 양상을 보였으나, 시각화만으로 계절성의 통계적 유의성을 판단할 수는 없다.
누락된 6개월은 실제 이용량이 0건인 기간이 아니라 원본 데이터에 관측값이 존재하지 않는 기간이다.

## 8. 분석의 한계

이번 SQL과 pandas 검산은 동일한 BigQuery 테이블을 사용하므로 원본 데이터의 정확성을 독립적으로 보장하지 않는다.
월평균 이용량은 누락된 6개월을 제외한 관측 월을 기준으로 산출했다.
시각화에서 나타나는 변화는 이용량 추세를 탐색하기 위한 것으로, 인과관계나 통계적 유의성을 검증한 결과는 아니다.

## 9. 결론

BigQuery와 Python을 연결하여 SQL 조회, pandas 집계, 시각화, 데이터 품질 검증을 수행했다.
SQL과 pandas의 집계 결과가 일치함을 확인했으며, 월별 누락 데이터를 보존하여 잘못된 시각적 해석을 방지했다.
